# IC CMOS Gates Homework

## Description

This repository contains a homework assignment for the **Integrated Circuit (IC)** course.

The assignment covers the design and analysis of basic CMOS logic gates, including:

* CMOS Inverter Gate
* CMOS NAND Gate
* CMOS NOR Gate

For each gate, the homework includes:

* Schematic and Icon
* Layout
* Simulation
* Discussion of the CMOS gate design

## Contents

The complete homework report is provided as a PDF file.

## Topics Covered

* CMOS Inverter Design
* CMOS NAND Design
* CMOS NOR Design
* Schematic Design
* Layout Design
* Circuit Simulation
